# 🛍️ 오늘의 핫딜 · 드림이의 특가 편집샵

로그인·방 입장 없이 누구나 볼 수 있는 **무료 웹 핫딜 편집샵**입니다.
GitHub Pages로 서비스되고, 상품은 `deals.json` 한 파일만 고치면 추가·수정됩니다.

- 라이브 주소: https://qordnsehd.github.io/today-hotdeal/
- 문의·알림: 카카오 오픈채팅 https://open.kakao.com/o/gxTOTTYi
- 전체 상품 모음: https://link.inpock.co.kr/to0719

## 1. 상품 추가하는 방법 (3단계)

### ① 상품 사진 넣기
`images/` 폴더에 넣습니다. 정사각형(1:1) 800~900px JPG를 권장합니다.
사진은 **각 판매처의 공식 상품 이미지**만 씁니다(제휴 페이지 og:image 또는 상세 이미지).

### ② `deals.json`의 `items` 배열에 상품 한 덩어리 추가
아래 블록을 복사해 값만 바꿉니다. 배열 맨 **앞쪽**에 넣을수록 위에 먼저 보입니다.

```json
{
  "id": "my-new-deal",
  "rank": null,
  "title": "상품 이름 그대로",
  "brand": "브랜드명",
  "store": "쿠팡",
  "category": "생활·가전",
  "badge": "91% 특가",
  "price": 11900,
  "originalPrice": 146000,
  "off": 91,
  "rating": null,
  "reviews": "1,308",
  "priceNote": "일반할인가 · 쿠폰에 따라 변동",
  "desc": "한 줄 소개 (스펙·특징)",
  "ship": "무료배송 · 내일 도착",
  "image": "images/my-new-deal.jpg",
  "links": [
    { "label": "쿠팡에서 11,900원에 보기", "url": "https://link.coupang.com/a/XXXX", "primary": true }
  ],
  "tags": ["검색어", "키워드"]
}
```

| 항목 | 설명 |
|---|---|
| `id` | 겹치지 않는 영문 ID (링크 공유 버튼도 이 값을 씁니다) |
| `rank` | 인기 카드에 표시할 순번(1~5). 없으면 `null` → 번호 배지 없음 |
| `store` | `쿠팡` · `네이버` · `네이버 브랜드스토어` · `토스쇼핑` (카드 버튼 문구가 여기서 자동 생성) |
| `category` | `생활·가전`, `겨울·방한`, `뷰티·케어`, `토스 특가` — 실제 상품이 있는 카테고리만 상단에 노출 |
| `badge` | 카드 우측 상단 배지 문구. `%`·`특가`가 들어가면 빨강, 나머지는 흰색 |
| `price` | 현재 판매가(숫자만). **판매 페이지에서 확인한 값만** 넣습니다 |
| `originalPrice` | 정가(취소선). 모르면 `null` |
| `off` | 할인율 숫자. 모르면 `null` |
| `rating` / `reviews` | 평점·리뷰 수. 없으면 `null` |
| `priceNote` | 가격 아래 강조 메모(쿠폰 조건 등). 12자 안팎으로 짧게 |
| `ship` | `·`로 구분해 최대 2개까지 배지로 표시 (예: `무료배송 · 내일 도착`) |
| `links` | 첫 번째가 주 버튼, 나머지는 보조 버튼 |

### ③ 스포트라이트(대표 1건) 바꾸기
`deals.json`의 `spotlight`에서 `id`만 바꾸면 그 상품이 상단 대형 배너로 올라갑니다.

```json
"spotlight": {
  "id": "pulio-v3-gift",
  "kicker": "MD PICK 1위",
  "headline": "배너에 크게 띄울 한 줄",
  "sub": "가격·구성 설명 한 줄"
}
```

### ④ 업데이트 날짜 바꾸기
`deals.json` 맨 위 `"updated": "2026-11-27"` 을 오늘 날짜로 바꿉니다.

### ⑤ 저장(커밋)하면 1분 뒤 자동 반영
GitHub 웹에서 파일을 열어 ✏️(Edit) → 수정 → **Commit changes**. 빌드가 없어 30초~1분이면 반영됩니다.

## 2. 파일 구조

```
index.html      화면 (스포트라이트·검색·카테고리 필터·카드 렌더링·링크 복사)
deals.json      상품 데이터 (여기만 고치면 됩니다)
images/         상품 사진 (공식 이미지)
.nojekyll       GitHub Pages가 파일을 그대로 서비스하도록 하는 표시
```

## 3. 지켜야 할 표시

- 제휴(대가성) 고지는 `index.html` 상단과 푸터에 있습니다. **지우지 마세요.**
- 가격·재고는 수시로 바뀌므로 "최저가" 단정 대신 확인 시점·조건을 함께 적습니다.
- 토스쇼핑은 웹에 가격이 노출되지 않아 등록가로 표기하고 "앱에서 확인" 문구를 함께 둡니다.
- 화장품·건강 관련 상품은 효능·치료 표현을 쓰지 않습니다.
