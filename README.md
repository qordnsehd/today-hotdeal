# 🛍️ 오늘의 핫딜 · 못산템 특가 게시판

로그인·방 입장 없이 누구나 볼 수 있는 **무료 웹 핫딜 게시판**입니다.
GitHub Pages로 서비스되고, 상품은 `deals.json` 한 파일만 고치면 추가·수정됩니다.

- 라이브 주소: https://qordnsehd.github.io/today-hotdeal/
- 문의·알림: 카카오 오픈채팅 https://open.kakao.com/o/gxTOTTYi
- 전체 상품 모음: https://link.inpock.co.kr/to0719

## 1. 상품 추가하는 방법 (3단계)

### ① 상품 사진 넣기 (선택)
`images/` 폴더에 사진을 넣습니다. 정사각형(1:1) 640×640 JPG를 권장합니다.
사진이 없으면 자동으로 색상 타일 + 이모지가 표시되므로 비워 두어도 됩니다.

### ② `deals.json`에 상품 한 덩어리 추가
`items` 배열의 맨 **앞쪽**에 아래 블록을 복사해서 붙이고 값만 바꿉니다.
(맨 앞에 넣을수록 게시판 위쪽에 먼저 보입니다.)

```json
{
  "id": "my-new-deal",
  "title": "상품 이름 그대로",
  "category": "생활·가전",
  "badge": "오늘의 추천",
  "price": 29900,
  "priceNote": "쿠폰 적용 시 19,900원",
  "image": "images/my-new-deal.jpg",
  "desc": "한 줄 소개 (스펙·특징)",
  "meta": ["리뷰 1,200", "무료배송", "내일 도착"],
  "links": [
    { "label": "쿠팡에서 보기", "url": "https://link.coupang.com/a/XXXX", "primary": true }
  ],
  "tags": ["검색어", "키워드"]
}
```

| 항목 | 설명 |
|---|---|
| `id` | 겹치지 않는 영문 ID |
| `category` | 아래 4개 중 하나: `생활·가전`, `뷰티·그루밍`, `겨울·방한`, `토스 특가` |
| `badge` | 카드 왼쪽 위 리본 문구. 필요 없으면 이 줄을 지우세요 |
| `price` | 숫자만 (예: `159000`). 모르면 `null` → "가격은 판매처에서 확인"으로 표시 |
| `priceNote` | 가격 아래 강조 문구 (쿠폰가·정가 등). 없으면 지우세요 |
| `image` | `images/파일명.jpg`. 없으면 `null` |
| `desc` | 카드에 보이는 한 줄 설명 |
| `meta` | 회색 태그 목록 (리뷰 수·배송 등) |
| `links` | 첫 번째가 주 버튼(빨강), 나머지는 보조 버튼(흰색) |
| `tags` | 검색에 걸리는 키워드 |

> ⚠️ 맨 끝 상품 뒤에는 쉼표가 없어야 하고, 그 앞 상품들 뒤에는 쉼표가 있어야 합니다.
> 저장 후 https://jsonlint.com 에 붙여 확인하면 오류를 바로 잡을 수 있습니다.

### ③ 업데이트 날짜 바꾸기
`deals.json` 맨 위 `"updated": "2026-11-27"` 을 오늘 날짜로 바꿉니다. 상단 배지에 표시됩니다.

### ④ 저장(커밋)하면 1분 뒤 자동 반영
GitHub 웹에서 파일을 열어 ✏️(Edit) → 수정 → **Commit changes** 를 누르면 끝입니다.
별도 빌드가 없고, 커밋 후 30초~1분이면 라이브 페이지에 반영됩니다.

## 2. 파일 구조

```
index.html      화면 (검색·카테고리 필터·카드 렌더링)
deals.json      상품 데이터 (여기만 고치면 됩니다)
images/         상품 사진
.nojekyll       GitHub Pages가 파일을 그대로 서비스하도록 하는 표시
```

## 3. 지켜야 할 표시

- 제휴(대가성) 고지는 `index.html` 상단 배너와 푸터에 들어 있습니다. **지우지 마세요.**
- 가격·재고는 수시로 바뀌므로 "최저가" 단정 대신 "판매처에서 확인" 문구를 함께 둡니다.
- 화장품·건강 관련 상품은 효능·치료 표현을 쓰지 않습니다.
